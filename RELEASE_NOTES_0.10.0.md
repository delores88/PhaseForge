# PhaseForge 0.10.0

Candidate release notes. Local installation and marketplace admission remain separate release checks.

## Scientific workbench

- Simulation, illustration, analysis and explanation requests have separate completion requirements. An illustration cannot fulfill a requested numerical simulation. Unsupported questions retain the original request and explain the missing capability.
- Heat conduction and incompressible fluid flow retain numerical fields, timestamps and measurements for playback and inspection. Presentation controls change the view without recomputing the experiment.
- Optional pinned AthenaK workers support gauge-wave checks and a bounded puncture diagnostic, including a supervised CUDA transport on this Windows machine. These require a separately registered runtime and suitable available resources. They do not establish a validated high-speed black-hole merger, calibrated physical velocity or numerical convergence.
- Resource admission checks current CPU, memory, storage and, where applicable, GPU availability. Retained outputs and stopping reasons remain inspectable when execution cannot complete.

## Inspection and navigation

- Visible camera and playback controls improve inspection of saved scenes, particles and numerical fields. Horizontal iteration cards restore direct navigation through earlier results.
- Results combines laboratory outputs with equation-experiment findings. Opening a result selects its exact record rather than an unrelated current run; useful equation and fabrication tools remain available in their own workspace.
- Failed or partial scientific output is labeled above the viewer, with access to the actual job evidence. Color and camera settings remain separate from numerical computation.
- Completion indicators behave as read acknowledgements, and navigation is independent of an active conversation or experiment.

## Long-running work

- Repeated tool failures or lack of progress stop further automatic provider calls and retain a needs-direction outcome. Ongoing useful work can continue with the chat time guardrail disabled.
- Resume checks the saved request and child-job capabilities before spending another provider call. Unsupported child restart does not discard its evidence or silently rerun the experiment.
- Recovery of large retained numerical output runs as a visible background operation with progress and exact-operation cancellation. It preserves the original scientific result and deadline.
- Agent activity records tool calls, handoffs, compaction, evidence and concise progress explanations. These records do not expose private model chain of thought.

## Delivery scope

Windows x64 only for this release. The transparent PF symbol belongs on the marketplace discovery card; two application screenshots belong on the download page. Version numbers alone do not certify that a candidate has passed installation and marketplace validation.

Scientific validity remains specific to the model, assumptions, data and checks used in each experiment. Real solver execution and a convincing rendering do not by themselves validate a scientific conclusion.
