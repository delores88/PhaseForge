# PhaseForge 0.10.0

Windows x64 scientific workbench update. Release installation and marketplace
admission are recorded separately from source verification.

Draft only: the required high-boost relativistic black-hole collision remains
unfulfilled. These notes describe verified work so far, not a completed release.

- Simulation requests now carry a durable output contract through agent turns,
  status updates and conversation compaction. Completion checks retained numerical
  evidence. A still image cannot satisfy a simulation request, and an unavailable
  physical capability is reported explicitly.
- New local heat-conduction and incompressible-flow solvers retain physical fields,
  measurements, checkpoints and playback states. Their documented scope is
  constant-property periodic 2D conduction and unforced periodic 2D incompressible
  Newtonian flow. Independent analytic, convergence and restart checks are retained.
- Generated scientific calculations can publish bounded particle trajectories or
  scalar fields to the native player with source hashes, units, times and model
  assumptions. Native capture and video exports reuse those states and preserve the
  source model's limitations. Publishing data does not establish physical validity.
- Stills and simulations have visible inspection controls. Horizontal iteration
  cards return below the viewer, with the newest result at the right. Explicit
  selection preserves the iteration being inspected during background work.
- Completed results are available by their exact run or job identity across legacy
  equation experiments and newer laboratory outputs. Historical equation tools
  remain available. Project completion markers behave as durable read/unread state.
- Explain with AI, suggested next steps and numerical reviews read the selected
  completed result using the conversation's model and visible work limit. The
  dedicated review route pins retained evidence and refuses new computation,
  rendering or edits. Navigation and delayed responses preserve their project.
- Scientific illustration remains available when requested, including editable
  Blender geometry. Numerical JSON output is readable without an empty image viewer.

Full numerical-relativity black-hole mergers, general thermodynamics, compressible
or multiphase flow and predictive biological or clinical models are not supplied by
these bounded solvers. Successful execution is distinct from numerical validation,
calibration and predictive usefulness.
